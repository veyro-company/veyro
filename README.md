# Veyro

Strona Veyro: strony i sklepy do sprzedaży kursów, e-booków, planów treningowych i konsultacji.

Kontakt: [@veyro_company](https://www.instagram.com/veyro_company/).

## Zawartość

- `index.html` — cała strona, style CSS i skrypty JavaScript.
- `assets/fitness-training.webp` — fotografia użyta w przykładowym projekcie kursu.

Do uruchomienia nie jest potrzebna instalacja pakietów ani kompilacja. Otwórz `index.html` w przeglądarce. Czcionki są pobierane z Google Fonts; bez połączenia z internetem przeglądarka użyje czcionki zastępczej.

## Wgranie kodu na GitHub

1. Rozpakuj archiwum.
2. Na https://github.com/new utwórz repozytorium `veyro`. Wybierz Private, jeśli kod ma pozostać prywatny, lub Public, jeśli chcesz go udostępnić.
3. W pustym repozytorium wybierz „uploading an existing file”. W istniejącym użyj „Add file” → „Upload files”.
4. Przeciągnij `index.html`, folder `assets` i ten plik `README.md`. Wgrywaj rozpakowaną zawartość, nie sam ZIP. `index.html` powinien znajdować się bezpośrednio w głównym katalogu repozytorium.
5. Zapisz pliki przyciskiem „Commit changes”.

Przeniesienie kodu do repozytorium nie uruchamia automatycznie publicznej witryny i nie łączy synchronizacji z dotychczasowym adresem strony.

## Hosting

Stronę można opublikować na hostingu obsługującym statyczne pliki HTML. Katalog publikacji powinien zawierać `index.html` i folder `assets`; polecenie budowania nie jest potrzebne.

GitHub Pages ma ograniczenia dotyczące hostingu biznesów online i stron nastawionych na transakcje. Dla firmowej strony Veyro proponujemy przechowywać kod na GitHubie i korzystać z osobnego hostingu.

Dokumentacja:
- Dodawanie plików: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
- Zasady GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
